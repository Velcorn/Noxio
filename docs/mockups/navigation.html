Noxio navigation mockups

Everything in the main screen moves to the bottom or into one search bar. Three proposals for the home screen, two for playlists, and the About page. Tabs, menus and fields are clickable. Example data only.

1. Home screen

Common to all three: the app name is gone. The top is a search bar with the sort and overflow buttons inside it. The overflow menu holds Listening stats, Settings and About. Songs, Albums, Artists, Genres and Playlists become bottom navigation. The mini player stays just above it.

2. Playlists

A playlist can be searched and sorted, and exported as an M3U file. Sorting by title, artist, album, duration, date added, or "playlist order" (the default, and the only one that allows drag to reorder). The overflow menu also offers a ReplayGain scan for the songs of the playlist.

3. About page

The page is renamed to Noxio. The Auxio credit stays, as the license requires, and it makes clear that Noxio is a fork and that upstream is not responsible for it. Links point to the Noxio repository.

Open question: ReplayGain

Calculating ReplayGain means decoding every song and measuring its loudness (EBU R128). Android has no built-in way to do that, so it needs a loudness library. It would run as a background job with a progress notification and write the values into Noxio's own database, not into your files. It works, but it is the largest item on this list, so I would do it last and as its own step. Try the menu item in the mockups to see where it would live.
